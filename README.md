# Sakthi Paramesh B - Developer Portfolio

A modern, responsive, and dynamic personal portfolio website for Sakthi Paramesh B, an AI & Full Stack Developer. This portfolio is beautifully designed to showcase professional experience, projects, skills, and certifications with smooth animations and a premium layout.

## 🚀 Technologies Used

This project is built using modern, industry-standard web technologies:

- **React.js** - Frontend UI Library (Bootstrapped with **Vite** for lightning-fast builds)
- **Tailwind CSS** - Utility-first CSS framework for custom, responsive styling
- **Framer Motion** - For fluid scrolling and element reveal animations
- **React Scroll** - For smooth navigation between page sections
- **React Icons & Bootstrap Icons** - For high-quality, scalable vector icons
- **Google Fonts** - Custom typography featuring *Poppins*, *Barlow Condensed*, *Inter*, and *Dancing Script*

## 🛠️ How to Run This Project Locally

Follow these step-by-step instructions to get the portfolio running on your local machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer (Version 16.0 or higher is recommended).

### Step 1: Open the Project Directory
Open your terminal (Command Prompt, PowerShell, or the integrated terminal in VS Code) and navigate into the project folder where the source code is located.

### Step 2: Install Dependencies
Before running the app, you need to install all the required packages and libraries. Run the following command:
```bash
npm install
```

### Step 3: Start the Development Server
Once the installation is complete, you can start the local development server by running:
```bash
npm run dev
```

### Step 4: View the Website in Your Browser
The terminal will provide a local URL (usually `http://localhost:5173`). Open your web browser and navigate to that link to view the portfolio!
